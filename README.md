## Issue Summary

This issue is asking for a working example in the cocotb repo that shows how to set up a simulation when your design uses precompiled or encrypted IP cores (a user mentioned to think Xilinx FFT, UNISIM libraries, etc.). The idea is to create a simple template they can actually copy and adapt.

The fix is more of an example project + maybe some docs using cocotb's Python Runner (the modern replacement for Makefiles since 1.9). Some community members have already built stuff like this privately, so there's prior art to reference.
